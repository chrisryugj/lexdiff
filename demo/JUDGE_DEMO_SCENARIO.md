## 장면 1 — "구어체로 검색해도 조문에 꽂힌다" (30초)

**입력**: 홈 검색창에 `인공지능법 30조`

**포인트 멘트**:
> "인공지능법이라는 법은 없습니다. 정식 명칭은 '인공지능 발전과 신뢰 기반 조성 등에 관한 기본법', 공식 약칭도 '인공지능기본법'이죠. 그런데 현장에서는 다들 인공지능법이라고 부릅니다. LexDiff는 이 비공식 약칭을 실시간으로 해소해서 **제30조로 바로** 데려갑니다."

- 자동완성 드롭다운에서 "인공지능 발전과 … 기본법 제30조"가 1순위로 뜨는 것 보여주기
- Enter → 인공지능기본법 **제30조(인공지능 안전성·신뢰성 검·인증등 지원)** 화면 직행

✅ 검증: headless Chrome — 검색 후 제30조 뷰 직행, 자동완성 1순위 확인 (2026-07-10)
⚠️ 폴백: 만약 선택 목록이 뜨면 1번째 항목 클릭 (동일 결과, +2초)

## 장면 2 — "조문에서 바로 AI에게 묻는다" (60~90초)

**동작**: 제30조 화면에서 "AI에게 이 조문에 대해 물어보기" 또는 검색창 AI 모드로
`고영향 인공지능 사업자가 지금 준비해야 할 의무는?`

**포인트 멘트**:
> "벡터 DB가 아니라 **법제처 API를 실시간으로 호출**합니다. 어떤 도구를 호출하는지 과정이 전부 보이고, 답변의 인용은 사후에 원문 대조 검증까지 거칩니다. 시행 6개월도 안 된 신법을 환각 없이 다루는 이유입니다."

- 진행 타임라인(도구 호출 로그) 잠깐 보여주기 → 스트리밍 답변 → 인용 배지 클릭해 원문 팝업

✅ 검증: `/api/fc-rag` 실측 — "음주운전 처벌 기준은?" 20.9초, 도구 4회 호출, 도로교통법 제148조의2 인용 (2026-07-10)
⚠️ 폴백: 릴레이 응답 지연 시 자동으로 Gemini 폴백됨 (UI에 엔진 표기) — 멘트로 "이중 엔진 이중화"로 승화

## 장면 3 — "스크롤을 따라오는 판례" (45초) ★ 신기능

**동작**: 검색창에 `도로교통법` (조문번호 없이) → 전체 조문 뷰 → 상단 **판례** 버튼 클릭

**포인트 멘트**:
> "법령 전문을 읽으면서 판례를 찾으려면 보통 창을 두 개 띄워놓고 왔다갔다 합니다. LexDiff는 **본문을 스크롤하면 지금 읽고 있는 조문의 판례가 오른쪽 패널에 실시간으로 따라옵니다**."

- 천천히 스크롤 → 패널 헤더가 "제1조 관련 판례" → "제14조 관련 판례 (8건)"으로 바뀌는 것 강조
- 판례 카드 하나 클릭 → 판시사항/요지 상세 → 닫기로 목록 복귀

✅ 검증: headless Chrome — 스크롤 시 제14조 관련 판례 8건으로 헤더·목록 갱신 (2026-07-10)

## 장면 4 — "과거 개정도 골라서 비교한다" (60초) ★ 신기능

**동작**: 검색창에 `도로교통법 44조` (음주운전 금지) → **AI 요약** 버튼

**포인트 멘트**:
> "제44조 음주운전 조항은 2026년 7월 1일 개정으로 **'약물' 정의가 마약류·환각물질까지 명시적으로 확대**됐습니다. 기존 서비스는 '현행 vs 직전'만 보여주지만, LexDiff는 **개정 연혁 100여 건 중 원하는 시점을 골라** 그 개정의 신·구 대조와 AI 해설을 볼 수 있습니다."

- 다이얼로그 우측 상단 셀렉터에서 `2026-07-01 시행 · 일부개정` 선택
- 결정론 diff(-13/+19: 약물 정의 신설)가 즉시 교체되는 것 보여주기 → "AI 해설 생성" 클릭 → 스트리밍 해설

✅ 검증: headless Chrome — 셀렉터 101개 옵션, 2026-07-01 선택 시 비교기준 배지 "2026-01-01→2026-07-01"로 갱신 + 약물 정의 diff 표시 (2026-07-10). AI 해설 스트리밍은 `/api/summarize` 실측 통과
⚠️ 폴백: 해설 생성이 30초 넘으면 diff 화면만으로도 메시지 전달 가능 (결정론 diff는 AI 무관, 즉시)

## 장면 5 — "전국 조례를 한 번에 벤치마킹" (60~90초)

**동작**: 홈 도구 카드 → **조례 벤치마킹** → 키워드 `빈집 정비` → 지자체 2~3곳 선택 (예: 가평군 vs 강릉시) → AI 비교 분석

**포인트 멘트**:
> "조례 담당자의 실제 업무입니다. 우리 동네 빈집 조례를 만들려면 다른 지자체 조례를 일일이 찾아 읽어야 하죠. LexDiff는 **조례 전문을 통째로 읽고 비교 축을 스스로 도출해 표로** 정리합니다 — 강릉시는 빈집을 임대주택·청년 창업공간으로 활용하는 조항까지 있다는 것까지요."

- 비교표 + 하이라이트 3~5개 확인 (어느 지자체가 선진적인지 포함)

✅ 검증: `/api/benchmark-analyze` 실측 — 가평군 vs 강릉시 "빈집 정비" 17.6초, 표 10행 정상 렌더(구분행·셀 규칙 검증 통과), 하이라이트 4건 (2026-07-10)
⚠️ 주의: Gemini 3 preview 503이 간헐 발생 → 서버가 지수백오프 3회 재시도 + lite 폴백 자동 처리. 만일 실패 시 재클릭 1회

## (선택) 장면 6 — "법이 바뀌면 어디까지 흔들리나" (90초, 시간 여유 시)

**동작**: 홈 도구 카드 → **법령 영향 추적** → `도로교통법`, 기간 2026-01-01 ~ 오늘

**포인트 멘트**:
> "상위법이 바뀌면 시행령, 시행규칙, 그리고 전국 조례까지 연쇄적으로 손봐야 합니다. 이 연쇄를 자동 추적하고 AI가 위험/검토/참고로 분류합니다."

⚠️ 첫 실행(콜드)은 1.5~3분, 같은 법령 재실행(웜)은 ~20초 — **시연 5분 전 준비 단계에서 같은 조건으로 1회 미리 돌려 캐시를 데워두면** 본 시연에서 20초 내 완주
✅ 검증: `/api/impact-tracker` 실측 — 도로교통법 2026-01-01~07-10, 웜 기준 19.8초 완주, 영향 항목 8건 + 심각도 분류 + 요약표 정상 (2026-07-10)
